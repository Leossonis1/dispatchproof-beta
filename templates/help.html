Basics

Getting Started

The minimum you need to run an installation through DispatchProof.

01

Find a Job on the Dashboard

  1. Open Dashboard.
  2. Use Search for a job name, site, contact, client, project, project number, or contact email.
  3. Optionally choose a Client, Project, or Status.
  4. Click Apply Filters.
  5. Use Clear All to return to every active installation.
The status tiles above the filters also work as quick status filters.
03

Create a Job

  1. Click New Job in the sidebar.
  2. Optionally choose a Client and Project.
  3. Enter the Job Name, Project / Site, and Installation Date.
  4. Enter the site contact name and email.
  5. Review the readiness checklist and reminder settings.
  6. Click Create Job.
Tip: jobs can stay unassigned and be added to a client/project later.
03

Edit Job Details

  1. Open the job.
  2. Click Edit Job Details at the top.
  3. Update the job/site name, installation date, contact information, or reminder settings.
  4. Click Save Job Details.
  5. Review Job Activity to see exactly what changed.
This does not replace Client/Project assignment, readiness evidence, arrival records, reports, or Office Notes.
05

Duplicate a Job

  1. Open the existing job you want to reuse.
  2. Click Duplicate Job at the top.
  3. Review the copied client/project, site, contact, checklist, and reminder settings.
  4. Choose the new Installation Date and edit anything that changed.
  5. Click Create Job.
The copy starts fresh. Readiness responses, arrival evidence, reports, activity history, and Office Notes are never copied.
06

Understand Job Status

NO RESPONSE

Readiness has not been confirmed yet.

REVIEW

A response needs office review.

READY

The site is confirmed ready to dispatch.

BLOCKED

The site is not ready.

ON SITE

Installer arrival was successful.

COMPLETED

The installation has been marked complete.

Daily Use

Everyday Workflows

The core actions used to manage a live installation.

06

Send a Readiness Request

  1. Open the job.
  2. Open the Readiness Request page.
  3. Review the site contact and checklist.
  4. Click Generate Readiness Email.
  5. During Free Beta, confirm it appears in Email Outbox.
  6. The site contact opens the secure readiness link and submits the checklist.
07

Record Installer Arrival

  1. Wait until the job is READY.
  2. Open the job and find the installer arrival section.
  3. Use Copy Installer Link for the field installer, or Record Internally.
  4. Choose Site Ready when the installer can proceed.
  5. Add the reporter name and photos if needed.
  6. Submit. The job moves to ON SITE.
08

Record a Failed Mobilization

  1. Open the installer arrival form.
  2. Choose Site Not Ready.
  3. Select the failure reason(s).
  4. Enter Crew Affected and Hours Lost.
  5. Add at least two arrival photos.
  6. Submit to create the failed mobilization record and report.
Equipment affected and installer notes are optional.
09

Complete a Job

  1. Open a job that is ON SITE.
  2. Click Mark Job Complete.
  3. Confirm the action.
  4. The job moves to Completed Jobs.
  5. The installer link is revoked, while history and evidence stay preserved.
10

Add an Internal Job Note

  1. Open the job.
  2. Scroll to Office Notes.
  3. Enter the update, call note, scheduling detail, or other internal information.
  4. Click Save Internal Note.
  5. The note is stamped with the signed-in user and time.
Internal notes never appear in client reports or public links.
11

Read the Job Activity Trail

  1. Open any job.
  2. Scroll to Job Activity.
  3. Each event shows the action, time, and person/type responsible.
  4. Use it to verify job creation, readiness, arrivals, assignments, reports, and completion.
12

Use Email Outbox

  1. Click Email Outbox.
  2. Open any generated email.
  3. Review the recipient, subject, branded preview, and secure shared link.
  4. During Free Beta, OUTBOX means DispatchProof generated the email but did not send it externally.
Organization

Clients & Projects

Group multiple installation jobs without changing the individual job workflow.

13

Create a Client

  1. Click Clients & Projects.
  2. Click New Client.
  3. Enter the client name and optional primary contact details.
  4. Save the client.
14

Create a Project

  1. Open the client.
  2. Click New Project.
  3. Enter the Project Name.
  4. Optionally add a project number, location, and notes.
  5. Save the project.
15

Assign an Existing Job

  1. Open the job.
  2. Find Client & Project.
  3. Open Change Assignment.
  4. Select the client and project.
  5. Click Save Assignment.
Choosing a project automatically uses that project’s client.
16

Create a Job from a Project

  1. Open Clients & Projects.
  2. Open the client, then the project.
  3. Click New Job.
  4. The Client and Project fields are preselected automatically.
  5. Finish the normal New Job form and create the job.
Reporting

Client Reports

Share a secure branded report for one installation.

17

Share a Single-Job Client Report

  1. Open the job.
  2. Find Installation Report.
  3. Click Client Report & Email.
  4. Preview the secure report first.
  5. Enter the client recipient and generate/send the report email.
  6. During Free Beta, review the generated message in Email Outbox.
18

Revoke a Client Report Link

  1. Open Client Report & Email.
  2. Find Secure Report Link.
  3. Click Rotate Secure Link.
  4. Confirm the warning.
  5. The old link stops working immediately and a new link replaces it.
Multi-Install Reporting

Combined Reports

Send one report covering every installation under a client or project.

19

Combined Client Report

  1. Click Clients & Projects.
  2. Open the client.
  3. Click Combined Client Report.
  4. Review the installations included.
  5. Click Open Combined Report to preview.
  6. Generate the combined report email for the client recipient.
20

Combined Project Report

  1. Open Clients & Projects.
  2. Open the client, then the project.
  3. Click Combined Project Report.
  4. Preview the combined report and verify all project jobs are included.
  5. Generate the report email or copy the secure link.
21

Rotate a Combined Report Link

  1. Open the Combined Client or Project Report setup page.
  2. Copy the current link if you want to test revocation.
  3. Click Rotate Secure Link.
  4. The old URL becomes invalid and the replacement link works immediately.

Administrator

Admin Tools

Owner and Administrator-only workflows.

23

Users & Access

  1. Open Users & Access.
  2. Use Add User to create an Operations or Administrator login.
  3. Use Edit User to change name, username, role, or access status.
  4. Use Administrator Password Reset only when the user cannot reset their own password.
Operations users can run jobs but cannot access administrative settings or the global Activity Log.
24

Company Settings

  1. Open Company Settings.
  2. Set company name and tagline.
  3. Add contact information and website.
  4. Upload the company logo.
  5. Choose the accent color and save.
25

Global Activity Log

  1. Open Activity Log.
  2. Review the latest system, user, job, report, and backup events.
  3. Click a linked job when you need the job-specific evidence and timeline.
Safety

Backup & Restore

Protect the live database, evidence uploads, users, clients, projects, and history.

26

Download a Backup

  1. Open Backup & Restore.
  2. Review the record counts.
  3. Click Download Backup ZIP.
  4. Save it somewhere you can find again.
  5. Always make a fresh backup before deploying a new DispatchProof version.
27

Restore After a Render Reset

  1. Open Backup & Restore.
  2. Select the latest DispatchProof backup ZIP.
  3. Run the restore.
  4. Wait for the verified success message.
  5. Confirm the job count, branding, users, clients/projects, and evidence returned.
The restore verification protects against the older SQLite sidecar-file problem.
