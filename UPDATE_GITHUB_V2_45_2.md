# DispatchProof V2.45.2 — Training Results Export

## What changed
- Admin Training now includes **Download All Results CSV**.
- Admin can download a separate CSV for each trainee.
- Each scenario export row includes trainee, role, scenario, status, questions completed, completion percent, coaching moments, attempt totals, and assignment/start/completion activity timestamps.
- Export remains coaching-focused: no pass/fail grade or punitive score is added.
- Training exports are Admin/Owner only.

## Deployment
No database migration and no new Render environment settings are required. Deploy normally over V2.45.1.
