# DispatchProof V2.39 — Polish & Context Help

## What changed
- Added **Help me understand this page** at the top of signed-in pages, linked to the closest Help & Tutorials section.
- Added **Other / Project-Specific Requirements** to the Readiness Checklist with **+ Add Another** and remove controls.
- Project-specific readiness items are saved with the job and preserved when duplicating a job.
- Users & Access actions now return to the relevant section instead of jumping to the top.
- Added confirmation prompts before disabling a user, turning team sharing off, removing a team member, or deactivating crew.
- Added consistent required-field markers on signed-in forms.
- Improved the Completed Jobs empty state with a clear next action.
- Kept all V2.37 user/team privacy rules and V2.38 user workspace backups unchanged.
