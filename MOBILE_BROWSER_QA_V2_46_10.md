# DispatchProof V2.46.10 — Real-Phone Smoke Test

Use the deployed site in Safari or Chrome on a phone. No native app install is required.

1. Sign in and confirm the dark mobile top bar appears with a menu button.
2. Open the menu and confirm the full DispatchProof navigation is available.
3. Tap Dashboard, Jobs/Schedule, Crew, Clients & Projects, Documents, Training, and My Account; the menu should close after navigation.
4. Confirm forms can be filled without needing pinch-to-zoom and buttons are easy to tap.
5. On Dashboard/Schedule/other table screens, swipe horizontally inside a wide table if needed; the whole page should not drift sideways.
6. Open a Job and test primary actions plus the More/Job Actions menu.
7. Open Crew/Subcontractors and confirm the shared subcontractor database is still available.
8. Rotate the phone once between portrait and landscape and confirm the page remains usable.
9. Return to a desktop browser and confirm the original left sidebar layout is unchanged.

If any one page still feels cramped, note the page name and what is cut off; that should be treated as a targeted mobile polish bug, not a new feature.
