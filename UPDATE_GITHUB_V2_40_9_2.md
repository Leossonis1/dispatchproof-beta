# DispatchProof V2.40.9.2 — Context Help Documents Fix

## What changed
- The Documents page **Help me understand this page** button now opens the start of the full **Documents** tutorial section instead of landing at only the Document Center card.
- Job Documents, Project Documents, Client Documents, Document Center, and Quick Upload are grouped under a dedicated **Documents** help section.
- The top Help navigation now jumps to that Documents section.
- When a page URL is on `#job-documents`, `#project-documents`, or `#client-documents`, the page-level Help button dynamically targets the matching document tutorial.

## Database
No database migration or reset is required.
